# Conduit

An API specifications for Minestom utilities.

## Why Conduit?

Vanilla Minestom lacks of many important features useful for plugin development, making the ecossytem fragmented and 
incomplete. Conduit aims to provide clear and concise API specifications, for developers to use and rely on.
